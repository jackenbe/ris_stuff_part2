RIS Channel Drills

part 2: the RIS itself

RIS channel drills: 24 problems

These follow the Wireless Pi RIS tutorial step by step: a channel as a sum of paths, one path through one RIS element, picking the best phase, then your real board. Work each one on paper first. All numbers use 5.5 GHz and λ ≈ 5.45 cm.

New formulas (from the tutorial)

Channel from many paths: \(\;h = \displaystyle\sum_i \eta_i\, e^{-j2\pi f_c \tau_i}\)

Through RIS element \(n\): \(\;h_{A,n}\cdot e^{j\theta_n}\cdot h_{B,n}\)

Received: \(\;r = (\Lambda + h_d)\,s, \quad \Lambda = \displaystyle\sum_n h_{A,n}\, e^{j\theta_n}\, h_{B,n}\)

Best phase: \(\;\theta_n = \angle h_d - \angle h_{A,n} - \angle h_{B,n}\)

Adding two arrows: \(\;|a+b|^2 = |a|^2 + |b|^2 + 2|a||b|\cos\psi\)

One rule that does most of the work

\(\big(A e^{j\alpha}\big)\big(B e^{j\beta}\big) = AB\, e^{j(\alpha+\beta)}\): multiply the lengths, add the angles.

A. A channel is a sum of paths

Each path is one arrow: its length is how strong the path is, its angle comes from its delay. Tutorial equations 1 to 3.

  1. One path with strength \(\eta = 0.5\) and delay \(\tau = 45.45\) ps. Find \(h\) in polar form and in \(a + jb\) form.

    Hint

    Fraction of a cycle is \(F\tau\). The minus sign in \(e^{-j\ldots}\) means the arrow turns clockwise.

    Show solution

    \(F\tau = (5.5\times10^9)(45.45\times10^{-12}) = 0.25\) cycle \(= 90°\)

    \(h = 0.5\,e^{-j90°} = 0.5(\cos(-90°) + j\sin(-90°))\)

    h = 0.5e^{−j90°} = −0.5j

  2. Two paths reach the receiver. Line of sight: \(\eta_0 = 1\), no delay. A wall bounce: \(\eta_1 = 0.6\), arriving 90.9 ps later. Find \(h\), then the power compared to line of sight alone, in dB.

    Show solution

    90.9 ps is half a cycle, so the wall arrow is at −180°: \(0.6e^{-j180°} = -0.6\)

    \(h = 1 + (-0.6) = 0.4\). Power ratio \(= 0.4^2/1^2 = 0.16\), and \(10\log_{10}0.16\)

    h = 0.4, about −8 dB

    An extra path made the signal weaker. That's a fade, and it's the problem an RIS is built to fix.

  3. Same wall, but now it arrives 181.8 ps late. Find \(h\) and the power in dB versus line of sight alone.

    Show solution

    181.8 ps is one full cycle, so the arrow is back at 0°: \(h = 1 + 0.6 = 1.6\)

    \(1.6^2 = 2.56\), \(10\log_{10}2.56\)

    h = 1.6, about +4.1 dB

    Same two paths, opposite outcome. Only the phase changed.

  4. The wall path is 1.00 m longer than line of sight. What angle does it add? Then: by how much would that extra length need to change to flip it by 180°?

    Hint

    Count wavelengths: extra length ÷ λ. Throw away the whole cycles.

    Show solution

    \(1.00 / 0.05454 = 18.33\) wavelengths. Keep 0.33, so \(0.33 \times 360° = 120°\), and the term is \(e^{-j120°}\).

    A 180° flip needs half a wavelength of change: \(\lambda/2\)

    −120°; a change of about 2.7 cm flips it

    Moving your phone a couple of centimeters can turn a good spot into a fade. That's why the RIS phases have to be set for where the receiver actually is.

Say it out loud: why can the same two paths give 0.4 in one spot and 1.6 a few centimeters away?

B. The complex detour: adding two arrows

The tutorial's \(|a+b|^2\) formula. \(\psi\) is the angle between the two arrows.

  1. \(|a| = 3\) and \(|b| = 4\). Find \(|a+b|\) when \(\psi = 0°\), \(90°\), and \(180°\).

    Show solution

    \(\psi = 0°\): \(9 + 16 + 24(1) = 49\)

    \(\psi = 90°\): \(9 + 16 + 24(0) = 25\)

    \(\psi = 180°\): \(9 + 16 + 24(-1) = 1\)

    7, 5, 1

    The 90° case is your old \(3 + 4j\): two arrows at right angles. Aligned gives the most, opposite gives the least.

  2. \(a = 2e^{j30°}\), \(b = 1e^{j150°}\). Find \(|a+b|\) with the formula, then check it by adding real and imaginary parts.

    Show solution

    \(\psi = 150° - 30° = 120°\), \(\cos120° = -0.5\)

    \(|a+b|^2 = 4 + 1 + 2(2)(1)(-0.5) = 3\)

    Check: \(a = 1.732 + 1j\), \(b = -0.866 + 0.5j\), sum \(= 0.866 + 1.5j\), and \(\sqrt{0.75 + 2.25} = \sqrt3\)

    |a + b| = √3 ≈ 1.73

Say it out loud: which term in the formula is the only one the RIS can change, and what value does the RIS want it to have?

C. One path through one RIS element

Three rotations in a row: transmitter to element, the element's own phase, element to receiver. Tutorial equation 5.

  1. Element has \(h_A = 0.5e^{j40°}\), \(h_B = 0.4e^{-j70°}\), and \(\theta = 0°\). Find \(h_A e^{j\theta} h_B\) in polar and \(a + jb\) form.

    Show solution

    Lengths multiply: \(0.5 \times 1 \times 0.4 = 0.2\). Angles add: \(40° + 0° - 70° = -30°\)

    \(0.2(\cos30° - j\sin30°)\)

    0.2e^{−j30°} ≈ 0.173 − 0.1j

  2. Same element, now set to \(\theta = 120°\). What's the new length and angle?

    Show solution

    Length: still \(0.5 \times 1 \times 0.4 = 0.2\). Angle: \(40 + 120 - 70 = 90°\)

    0.2e^{j90°} = 0.2j (same length, new direction)

    \(|e^{j\theta}| = 1\), so the element can only turn the arrow. It can never make it longer. That's what "passive" means.

  3. The direct path is \(h_d = 0.1e^{j60°}\). What \(\theta\) makes this element's arrow point the same way as \(h_d\)? Check your answer.

    Show solution

    \(\theta = \angle h_d - \angle h_A - \angle h_B = 60° - 40° - (-70°)\)

    Check: \(40° + 90° - 70° = 60°\) ✓

    θ = 90°

Say it out loud: why does the best-phase formula subtract both \(\angle h_A\) and \(\angle h_B\)?

D. Two elements plus the direct path

A tiny RIS you can do by hand. Use these numbers for all four problems.

\(h_d = 0.3e^{j0°}\)

Element 1: \(h_{A,1} = 0.5e^{j20°}\), \(h_{B,1} = 0.4e^{j50°}\)

Element 2: \(h_{A,2} = 0.5e^{-j120°}\), \(h_{B,2} = 0.4e^{j10°}\)

  1. Both elements set to \(\theta = 0°\). Find each element's arrow, \(\Lambda\), and \(|\Lambda + h_d|\).

    Show solution

    Element 1: \(0.2e^{j(20+50)°} = 0.2e^{j70°}\)

    Element 2: \(0.2e^{j(-120+10)°} = 0.2e^{-j110°}\)

    70° and −110° are exactly opposite, so they cancel: \(\Lambda = 0\)

    Λ = 0, |Λ + h_d| = 0.3

    An unconfigured RIS can do nothing at all, or even hurt. The board only helps once you set the phases.

  2. Find the best \(\theta_1\) and \(\theta_2\).

    Show solution

    \(\theta_1 = 0° - 20° - 50° = -70°\) (same as 290°)

    \(\theta_2 = 0° - (-120°) - 10° = 110°\)

    θ₁ = 290°, θ₂ = 110°

  3. With those phases, find \(|\Lambda + h_d|\) and the power gain over the unconfigured board, in dB.

    Show solution

    Every arrow now points at 0°, so lengths just add: \(0.3 + 0.2 + 0.2 = 0.7\)

    \((0.7/0.3)^2 = 5.44\), \(10\log_{10}5.44\)

    0.7, about +7.4 dB

  4. Now make it 1-bit: round each \(\theta\) to 0° or 180°. Find \(|\Lambda + h_d|\) and the loss compared to problem 12.

    Hint

    After rounding, find each element's new arrow angle. They may line up with each other but not with \(h_d\). Then use the formula from section B.

    Show solution

    290° is closer to 360° (0°), so \(\theta_1 \to 0°\). 110° is closer to 180°, so \(\theta_2 \to 180°\).

    Element 1: \(70° + 0° = 70°\). Element 2: \(-110° + 180° = 70°\). Both at 70°, so \(\Lambda = 0.4e^{j70°}\)

    \(|\Lambda + h_d|^2 = 0.16 + 0.09 + 2(0.4)(0.3)\cos70° = 0.25 + 0.082 = 0.332\)

    \(\sqrt{0.332} = 0.576\), and \(10\log_{10}(0.332/0.49)\)

    ≈ 0.58, about −1.7 dB versus ideal

    Bonus with 2-bit: 290° → 270° and 110° → 90°, both arrows at 50°. \(|\cdot|^2 = 0.25 + 0.24\cos50° = 0.404\), only −0.8 dB. Same pattern as part 1.

Say it out loud: in problem 13 the two elements still agreed with each other. So what exactly did 1-bit cost you?

E. A reflector has two angles

With \(d = \lambda/2\), the phase step between neighbors is \(180°\,(\sin\theta_{out} - \sin\theta_{in})\). Angles are measured from the board's normal, and \(\theta_{out} = \theta_{in}\) is the plain mirror direction.

  1. The wave hits head-on (\(\theta_{in} = 0°\)) and you want it to leave at \(\theta_{out} = 30°\). Find the step and the phases of the first four elements.

    Show solution

    \(180°(0.5 - 0) = 90°\)

    step 90°: 0°, 90°, 180°, 270°

    Same as your steering weights from part 1, because a head-on wave adds no phase of its own.

  2. \(\theta_{in} = 25°\), \(\theta_{out} = 25°\). What's the step, and what is the board doing?

    Show solution

    \(180°(\sin25° - \sin25°) = 0°\)

    0°: every element the same, so it acts as a plain mirror

  3. \(\theta_{in} = 30°\), \(\theta_{out} = 0°\). Find the step and the first four phases.

    Show solution

    \(180°(0 - 0.5) = -90°\)

    0°, −90°, −180°, −270° → wrap to 0°–360°

    step −90°: 0°, 270°, 180°, 90°

  4. The board is set for problem 14 (step 90°). The transmitter moves, so the wave now arrives from \(\theta_{in} = 10°\). Where does the beam go?

    Show solution

    The step is fixed, so \(90° = 180°(\sin\theta_{out} - \sin10°)\)

    \(\sin\theta_{out} = 0.5 + 0.174 = 0.674\)

    θ_out ≈ 42.4°

    The beam doesn't vanish. It shifts, like a tilted mirror when the flashlight moves. That's why the controller has to know where the transmitter is.

Say it out loud: why does a flat board with every element at the same phase behave like a mirror?

F. Your 8×8 board

Element \((m, n)\) sits in column \(m\) and row \(n\). Its phase is \(m\cdot\Delta_x + n\cdot\Delta_y\): one step for each direction.

  1. Head-on wave. Steer to 30° along \(x\) and to 14.5° along \(y\) (\(\sin = 0.25\)). Find \(\Delta_x\), \(\Delta_y\), and the phase of elements (3, 5) and (7, 7).

    Show solution

    \(\Delta_x = 180°(0.5) = 90°\), \(\Delta_y = 180°(0.25) = 45°\)

    (3, 5): \(270° + 225° = 495° \to 135°\)

    (7, 7): \(630° + 315° = 945° \to 225°\)

    Δx = 90°, Δy = 45°; 135° and 225°

  2. Same board, 1-bit. What do those two elements get set to, and how many on/off control bits does the whole board need? What about 2-bit?

    Show solution

    135° is 45° from 180° and 135° from 0°, so → 180°. 225° → 180° too.

    One bit per element: 64. Two bits per element: 128.

    both 180°; 64 bits for 1-bit, 128 for 2-bit

    That bit count is what your microcontroller and shift registers have to drive.

G. Why it takes many elements

  1. Each RIS hop is weak: \(|h_{A,n}| = |h_{B,n}| = 0.01\). The direct path is \(|h_d| = 0.01\). How many perfectly aligned elements does it take to match the direct path? With your 64 elements, what's the power gain over direct alone?

    Show solution

    One element: \(0.01 \times 0.01 = 0.0001\). To reach 0.01: \(N = 100\)

    64 elements: \(\Lambda = 0.0064\), total \(0.0164\). \((0.0164/0.01)^2 = 2.69\), \(10\log_{10}2.69\)

    100 elements; about +4.3 dB with 64

    Each element pays the loss twice (in and out), so one element barely counts. The RIS only matters with many elements, and it matters most when the direct path is blocked.

  2. Same setup, but a person blocks the direct path completely (\(h_d = 0\)). Compare the 64-element RIS power to the original unblocked direct path, in dB. Then do it for 16×16.

    Show solution

    8×8: \((0.0064/0.01)^2 = 0.41\), \(10\log_{10}0.41\)

    16×16: \(\Lambda = 256 \times 0.0001 = 0.0256\), \((2.56)^2 = 6.55\), \(10\log_{10}6.55\)

    8×8: about −3.9 dB; 16×16: about +8.2 dB

    Power grows with \(N^2\): 4× the elements gives 16× the power, +12 dB. That's the trade-off behind 8×8 versus 16×16.

H. Where h_A and h_B come from

In a simulation you calculate each channel from distance. Free space, nothing in the way: \(\;h = \dfrac{\lambda}{4\pi d}\,e^{-j2\pi d/\lambda}\). The first part sets the length (how weak), the second sets the angle. \(d\) is in meters.

  1. The transmitter is 2 m from an RIS element. Find \(|h_A|\) and its angle.

    Hint

    Length: plug into \(\lambda/(4\pi d)\). Angle: count wavelengths in 2 m, keep the leftover, and remember the minus sign.

    Show solution

    Length: \(0.0545 / (4\pi \cdot 2) = 0.0545/25.13 \approx 0.00217\)

    Angle: \(2 / 0.0545 = 36.67\) λ. Keep 0.67, so \(0.67 \times 360° = 240°\)

    h_A ≈ 0.00217 e^{−j240°}

  2. Move the transmitter to 4 m. What happens to the length, the power in dB, and the angle?

    Show solution

    Length: double the distance, half the length: \(0.00108\). Power: \(10\log_{10}(0.5^2) = -6\) dB

    Angle: \(4/0.0545 = 73.33\) λ, keep 0.33, so 120°

    ≈ 0.00108 e^{−j120°}, −6 dB

    Every doubling of distance costs 6 dB. Small moves barely change the length but can swing the angle all the way around.

  3. The transmitter is far away at 30°, about 2 m from element 0. Element 1 is \(\lambda/2\) over, so its path is \(d\sin30° = 1.36\) cm longer. How much do the two elements differ in length and in angle?

    Show solution

    Length: \(2/2.0136\), under a 1% difference, so basically the same

    Angle: \(1.36 / 5.45 = 0.25\) λ, so 90°

    same length, 90° apart

    Far away, only the angle changes between neighbors, by exactly the step from part 1. That's why the old \(a_n = e^{-j2\pi\frac{d}{\lambda}n\sin\theta}\) works: it's this formula when the transmitter is far.

  4. One element sees the transmitter at \(d_A = 2\) m and the receiver at \(d_B = 3\) m. The direct path is 4 m. How long is the element's arrow \(|h_A h_B|\), and how many perfectly aligned elements would it take to match the direct path?

    Show solution

    \(|h_A| = 0.00217\), \(|h_B| = 0.0545/(4\pi\cdot3) = 0.00145\), product \(\approx 3.14\times10^{-6}\)

    Direct: \(0.0545/(4\pi\cdot4) = 0.00108\)

    \(0.00108 / 3.14\times10^{-6} \approx 345\)

    ≈ 3.1 × 10⁻⁶; about 345 elements

    This is the simplest model, and it's pessimistic. Real elements have area and antenna gain, which the ETSI model in the MathWorks example includes. But it shows why the RIS shines most when the direct path is blocked.
